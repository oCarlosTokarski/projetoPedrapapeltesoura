# Pedra, Papel e Tesoura ✊📄✂️

Um projeto simples de **Pedra, Papel e Tesoura** feito com **HTML, CSS e JavaScript**, usando o DOM para atualizar a página conforme o jogador faz suas escolhas.

A ideia foi praticar principalmente a manipulação do DOM, funções, condicionais e também o uso do `localStorage` para salvar a pontuação.

## 🎮 Como funciona

O jogador pode escolher entre:

* 🪨 Pedra
* 📄 Papel
* ✂️ Tesoura

Depois da escolha, o computador faz uma jogada aleatória e o jogo mostra quem ganhou, perdeu ou se deu empate.

A pontuação fica sendo contabilizada durante as partidas:

* **Vitórias**
* **Derrotas**
* **Empates**

Também existe um botão para **resetar a pontuação**.

## 💾 Pontuação salva

A pontuação é armazenada no `localStorage` do navegador. Isso significa que, mesmo fechando ou atualizando a página, a pontuação continua salva.

Ao clicar em **Resetar pontuação**, os valores voltam para zero e o registro salvo no navegador é removido.

## 🎯 Objetivo do projeto

Esse projeto foi feito como uma forma de praticar JavaScript no navegador, principalmente:

* Manipulação de elementos com `querySelector`
* Eventos através do `onclick`
* Uso de `Math.random()` para movimento aleatório da maquina
* Estruturas condicionais
* Funções
* Atualização do conteúdo da página
* Armazenamento de dados com `localStorage`

É um projeto simples, mas ajuda bastante a entender como o JavaScript consegue deixar uma página HTML interativa.
